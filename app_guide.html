Multi-File Selection & Batch Sharing

NEW in v3.0

Select one or all files with checkboxes for seamless batch operations. Instant preview continues to reflect whichever file is being checked.

  • 1
    Individual & Select All: Tap any checkbox to select a file, or use the header checkbox to select all files in the current folder at once.
  • 2
    Continuous Instant Preview: Checking a box keeps the top preview card active, letting you verify document contents before sharing or deleting.
  • 3
    Batch Share Sheet: Tap Share on the batch toolbar to send multiple selected files to WhatsApp, Gmail, Drive, or Telegram using Android's native Intent.ACTION_SEND_MULTIPLE.
  • 4
    Safe Batch Deletion: Tap Delete with confirmation. Files are purged and the list updates instantly on the same page.

Live Instant Top Preview

Zero App Switching

No need to launch external viewers just to check a receipt or verify a script. Tap any file to instantly see its contents in the top pane.

  • PDF
    Vector Page Rendering: Crisp, clear rendering of page 1 using native Android PdfRenderer.
  • IMG
    High-Definition Photos: Instant image thumbnails with dimensions, size, and date stamp.
  • AUD
    Inline Audio Player: Play voice notes, podcasts, or songs with a scrubbable slider and duration counter.
  • HEX
    Binary Inspector: Formatted 16-byte hex dump view (Offset | Bytes | ASCII) for logs and unknown files.

State Memory & Zero Root Reset

Seamless Continuity

Files+ remembers your exact working location and prevents accidental jumps to the device root.

  • A
    Folder & File Memory on Exit: Whenever you close or exit the app, Files+ saves your active directory path, active tab, and currently previewed file. When you reopen the app, you resume right where you left off.
  • B
    Safe Deletion Navigation: After deleting any single or batch of files, the app remains on the exact same folder/page instead of dropping back to the root directory (/).
  • C
    Storage Fallback Guard: Navigating up through parent directories stops cleanly at user storage (/storage/emulated/0), preventing empty root folder errors.

🔍 Deep Multi-Format Content Search Engine

📚 Reads Inside Documents

Unlike standard file explorers that only match filenames, Files+ inspects the actual text inside PDFs, Word (.docx), Excel (.xlsx), CSV, TXT, and vCards (.vcf).

Apache PDFBox + POI Extractor

📞 Smart Phone Number Matching

Search any phone number (e.g. 9876543210) and Files+ finds it even if formatted as +91 98765-43210 or (987) 654-3210.

Normalized Digit Matcher

🔔 Non-Blocking Background Scanning

Heavy deep scans run in a foreground service without freezing the UI. A system notification keeps you updated and automatically syncs when the scan finishes.

Android Notification Sync

✨ Smart Auto-Organizer & Color Tagging

🗂️ 1-Tap Category Sorting

Messy Downloads or DCIM folders? One tap automatically categorizes files into /AutoOrganized/ subfolders (Images, Documents, Videos, Audio, Sheets, Code, Archives).

🏷️ Cross-Folder Tagging

Create custom tags like #Taxes, #Work, or #Receipts. Filter all files on your device with that tag in a single tap, no matter what folder they are in.

🛡️ Collision-Proof Safety

Automatically avoids duplicate overwrites (renaming duplicates like receipt_1.pdf) and preserves critical system directories (/Android/data).

📖 Quick Guide: 3-Dot Menu Drawer

Tap the ⋮ (3-Dot Menu) at the top right of the navigation bar to access essential tools:

  • 📁 File Explorer: Switch back to the standard directory browser.
  • 🔍 Deep Keyword Search: Search inside documents and spreadsheets across whole storage.
  • 🏷️ Tagged Files: Browse your color-coded tagged files collection.
  • 📊 Storage Partitions Stats: View used vs free disk space across device partitions.
  • ✨ Auto Organize Files: Open the 1-tap categorization dialog.
  • ➕ New Folder / New Text File: Create directories and files directly.
  • 🌙 Dark / Light Theme: Toggle OLED slate dark mode or bright day mode.
  • 🔤 Font Size: Adjust typography scale from 85% to 150%.
  • 📖 How It Works / App Guide: Open this interactive guide and demonstration page directly inside the app!
